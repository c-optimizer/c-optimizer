C-Optimizer é um aplicativo desktop moderno desenvolvido para otimização de sistema, redução de input lag, limpeza de temporários e monitoramento de hardware em tempo real.

🚀 Tecnologias Utilizadas:
- Frontend: React.js + Tailwind CSS (Interface Neon / Dark Mode)
- Desktop Runtime: Electron + Vite
- Backend & IPC: Node.js + PowerShell Execution (`child_process`) + `systeminformation`
- Arquitetura: Multi-language (PT-BR, EN-US, ES-ES) com rotas dinâmicas

📌 Funcionalidades Principais:
- Dashboard de Telemetria (CPU, GPU, RAM, Armazenamento e SO em tempo real)
- Módulo de Otimizações de Desempenho e Ajustes de Latência (DWM, Timer Resolution, HAGS, Game Mode)
- Ferramentas de Limpeza Física (Pastas temporárias, caches e desfragmentação/TRIM)
- Gerenciamento de Serviços, Privacidade e Aplicativos Essenciais
- Sistema de Restauração e Gerenciamento de Licenças (Em desenvolvimento)
